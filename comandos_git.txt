git init .                                  -> cria um repositório git na pasta (diretório) atual
git status                                -> mostra o status do trabalho (de cada arquivo)
git add 'nome_do_arquivo' -> adiciona arquivos para ser commitado
git commit -m 'mensagem' -> faz commit do que estava para ser commitado
git log -> mostra todo o histórico de commit de um repositório

## FLUXO DE TRABALHO
 1. Criar o diretório (pasta) do projeto
2. Iniciar o git dentro do diretório (git init .)
3. Edita ou criar arquivos
4. git status
5. git add <nome arquivo>
6. git status
7. git commit -m "mensagem estranha"
8. git status
9. volta para o passo 3
